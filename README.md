# The General Store – Inventory and Sales Management System

## Project Description

This project is an Inventory and Sales Management System developed for The General Store, Menlyn Park, Pretoria.

The system helps manage daily store operations by improving the way products, suppliers, sales, inventory and customer feedback are recorded and monitored.

## Main Features

- Product Management
- Supplier Management
- Sales Management
- Automatic Stock Updates
- Inventory Management
- Low Stock Monitoring
- Customer Feedback Management
- Sales Reports
- Dashboard with Recent Sales and Inventory Overview

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS

## How to Run the Application

1. Install Python.
2. Open the project folder.
3. Create a virtual environment.
4. Install the required packages:

   pip install -r requirements.txt

5. Initialise the database:

   python database.py

6. Start the application:

   python app.py

7. Open your browser and visit:

   http://127.0.0.1:5000
